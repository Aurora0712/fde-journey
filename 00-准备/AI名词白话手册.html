AI 名词白话手册 · ZERO-BASE

把 AI 黑话翻译成人话

这份手册不假设你懂任何技术。所有概念都用公路养护的场景打比方。看完之后你就知道那些缩写到底是个啥、为什么要有它、以及什么时候根本不需要它。

先建立一张全景图：整个 AI 系统，其实就是「一个脑子 + 三样外挂」

想象你单位新来了一个人：

  • 脑子（LLM）：把全国所有养护规范、报告、案例都读过的老工程师。但他从不翻书，凭印象回答——所以他记得不准，还会一本正经地编。
  • 外挂一 · 档案柜（RAG）：给他配了一个档案柜，回答前必须先翻规范，照着答。解决他"记不准、爱瞎编"的毛病。
  • 外挂二 · 手脚和工具（Tool / MCP）：给他配了对讲机、巡检 APP、计算器。他不只是能说，还能查数据库、发工单、操作 Excel。
  • 外挂三 · 自己干活的脑子（Agent）：从"你问一句他答一句"，升级成"你给个目标，他自己拆步骤、干活、干完汇报"。

后面所有的名词，都是这四个东西的零件和配件。记住这张图，你就不会迷路。

第 1 层你花钱买的到底是什么

这几个词解释的是"模型本身"。搞懂它们，你就知道钱花在哪、为什么 AI 会犯错。

LLM Large Language Model · 大语言模型 最基础

一句话：一个把海量文本都读过、专玩"文字接龙"的程序。你给它开头，它猜下一个字该是什么，一个字一个字往下接。
用人话说就像一个把《公路养护技术规范》《桥梁养护规范》和全国几十年的养护报告全都背过的老工程师。但他不翻书，靠印象答。绝大多数时候答得挺好，偶尔会记岔——而且记岔的时候他说得一样理直气壮。
它的三个致命短板（这三条决定了后面所有技术为什么存在） ① 知识有截止日期：训练完之后的规范修订、新文件，他完全不知道。
② 没手没脚：不能联网、不能查你的数据库、不能操作 Excel，只能"说话"。
③ 会幻觉：想不起来的时候就编，而且一本正经地编。
为什么你要知道：你现在用的豆包、DeepSeek、ChatGPT，全都是 LLM 套了个聊天界面。"大模型"不是一个神秘的智能生命，本质上就是个概率游戏——只不过玩了几千亿次，玩得特别溜。

Token 词元 · 计费单位

一句话：AI 不认识字，只认识数字。它把你的话切成一小块一小块，每块叫一个 Token。中文大约 1 个汉字 ≈ 1–2 个 Token。
用人话说就是按方计量的砂石料——你发多少字、它回多少字，都要过磅收费。你跟它说"在吗"，它回"在的"，这来回几个字已经记账了。
为什么你要知道：API 是按 Token 数收钱的。这就是为什么课表里 W7 要你"计算单条成本"——不了解 Token，你的系统跑起来可能账 single 条几毛钱，跑一万条就是几千块。

上下文窗口 Context Window

一句话：AI 一次性能"看见"的材料总量上限。超出的部分它直接忘掉。
用人话说就是办公桌的桌面大小。你摊得下多少张图纸，他就只能看多少张。你把一本 200 页的规范整本扔上去，前面的内容就被挤到地上了——他不是故意不看，是真看不见。
为什么你要知道：这直接解释了为什么不能"把整本养护规范丢给它"（塞不下），也就解释了下一层的 RAG 为什么非有不可。

API / 调用 API Application Programming Interface

一句话：别人把模型做好开放出来，你按量付费、远程使用。你不用自己造模型。
用人话说不自建搅拌站，直接买商品混凝土。你自己不烧水泥、不配骨料，一个电话（发个请求）送过来，按方（按 Token）结账。
为什么你要知道：FDE 这个岗位99% 的情况都不训练模型，只是调用别人的模型。所以别被"我不会训练模型"吓住——那根本不是这个岗位要做的事。

微调 Fine-tuning Fine-tune 你大概率用不上

一句话：拿你自己的数据，把一个通用模型再训练一遍，让它变成"你们单位的专用模型"。
用人话说把那位通用老工程师送去参加你们省的专项培训，让他专门熟悉你们的路况和习惯。
为什么你用不上：贵、慢、而且要大量标注数据。FDE 的共识是：先试 RAG，RAG 不行才考虑微调。课表里没给你排微调，就是因为这个。

第 2 层怎么让它听你的话

这几个词是"用法"。搞懂它们，你的 AI 输出质量会立刻上一个台阶——不需要写任何代码。

Prompt / 提示词 提示词 立刻能用

一句话：你发给 AI 的那段话，包括任务、背景、格式要求、限制条件。研究怎么把这段话写好，就叫"提示词工程"。
用人话说就是给施工班组的技术交底书。交底写得含糊，干出来就歪；写得越具体，出来的活越符合预期。

❌ 差：帮我整理一下巡查记录
✅ 好：你是公路养护技术员。把下面这段巡查口播整理成表格，字段为：桩号、病害类型、严重等级、位置描述。桩号格式必须是 K12+300 这种。不确定的字段写"待确认"，不要自己猜。只输出表格，不要解释。
为什么你要知道：这是唯一一个你今天学了明天就能用、且不需要写代码的技能。课表 W2 的 D9 就是专门练这个。

结构化输出 / JSON Structured Output

一句话：强制 AI 按表格填，而不是写一篇作文。
用人话说要求安全员填标准化的检查表，而不是写一段随感。检查表能直接进电脑统计，随感不能。
为什么你要知道：AI 输出一段话，你的程序没法用；输出固定格式的表格，才能自动汇总成报表。这是从"聊天"走向"生产"的第一道坎。

幻觉 Hallucination Hallucination 最重要的问题

一句话：AI 一本正经地编造不存在的事实。
用人话说那位老工程师记不清规范第几条了，但他不会说"我不知道"——他会现编一条听起来很像那么回事的条款。你要是不去查原文，根本发现不了。
为什么你要知道：这是 AI 落地失败的第一大原因。养护建议如果编了一条不存在的规范，后果比不干活还严重。所以课表里 D2 的作业专门要你设一条 gate："给不出规范出处 → 不许输出建议"。

Gate / 检查点 Gate

一句话：在流程的中间设一道卡，不符合条件就不放行，转人工或报错。
用人话说工序交接验收。上一道工序没验收合格，下一道不许开工。桩号格式不对 → 卡住；必填字段缺了 → 卡住；答不出规范出处 → 卡住。
为什么你要知道：这是不用写复杂代码也能大幅提升可靠性的手段。课表 D2 的硬指标就是"至少 3 个 gate"。

第 3 层怎么让它别瞎编（RAG）

RAG 是目前企业 AI 落地最主流、也最适合你的技术方案。这四个词是一套的，一起看。

RAG Retrieval-Augmented Generation · 检索增强生成 核心中的核心

一句话：不让 AI 凭记忆回答，而是先去你的资料库里把相关段落翻出来，摊在桌上，让它照着答。
用人话说把闭卷考试改成开卷考试。而且不是把整本规范丢给他（桌子放不下），是先帮他精准翻到那几页，再让他照着答。
你的提问："K12+300 横向裂缝该怎么处理？"
        ↓
   先去资料库检索（不是让 AI 凭印象）
        ↓
   找出《公路养护技术规范》第 X 条原文 + 类似历史工单
        ↓
   把这几段原文和问题一起交给 AI
        ↓
   AI 照着原文回答，并注明出处
为什么你要知道：它同时解决了"知识过时"和"幻觉"两个问题。你要做的养护规范问答系统（课表 W8）就是这件事。而且这是你最有优势的地方——规范条文你比任何程序员都熟。

分块 Chunking

一句话：把一本厚规范切成一小段一小段再存进资料库。
用人话说不能把整本规范塞进档案柜的一格。要按条目拆开装订，一条一格，以后才能精准抽出来。切太碎会断章取义，切太粗又会夹带无关内容——这个"切多大"本身就是 RAG 的关键手艺。

Embedding / 向量 嵌入 · Embedding

一句话：把一段文字变成一串数字（一个坐标）。意思相近的文字，坐标就靠得近。
用人话说档案柜不按书名拼音排，而是按"内容像不像"排。你问"裂缝怎么处理"，它能找到写"龟裂、横缝、纵缝修补"的那几段——哪怕标题里一个"裂缝"都没有。这就是"语义检索"，比关键词搜索聪明的地方。

向量数据库 Vector Database

一句话：专门存这些"文字坐标"、并能飞快找出"最相近的几段"的柜子。
用人话说一个知道你问的是什么、直接把最相关的那几份资料抽出来的智能档案员。常见的有 FAISS、Chroma（本地、免费、简单）、Pinecone（云端）。你从 Chroma 或 FAISS 起步就够。
为什么你要知道：整条链是 分块 → 变向量 → 存进向量库 → 提问 → 找最像的几段 → 交给 AI 照着答。这就是 RAG 的全部。

第 4 层怎么让它动手干活

前三层的 AI 只会"说"。这一层开始，它能"做"。

工具调用 Tool Calling

一句话：让 AI 能用外部工具——查数据库、发工单、操作 Excel、搜网页。
用人话说给那位老工程师配了对讲机、巡检 APP 和计算器。他不再只是"能说怎么做"，而是能自己查数据、下工单。
注意：他只负责"决定调哪个工具、传什么参数"，真正干活的是外面的程序。就像所长动嘴、班组跑腿。

Agent / 智能体 Agent

一句话：你只要给一个目标，它自己拆步骤、调工具、遇到错自己反思重来，干完才汇报。
用人话说从一个你问一句他答一句的顾问，升级成一个能自己带班组去现场把活干完的施工员。

普通聊天：你说"整理巡查记录"→ 它问"什么格式的？"
Agent：你说"把上周巡查记录整理成报表发给所长"→ 它自己读文件、清洗数据、套模板、生成报表、发送，全程不问你。
为什么你要知道：但它更贵、更慢、错了会连环错。Anthropic 官方反复强调：能用简单方式解决就不要上 Agent。课表 D2 那道"Workflow 还是 Agent"的题，考的就是这个判断力。

Workflow / 工作流 Workflow

一句话：步骤提前写死的固定流水线。第一步干什么、第二步干什么，你来定。
用人话说按工序卡施工：第一步做什么、第二步做什么、验收标准是什么，全都规定好。
对比 Agent：现场看着办。灵活，但不可控。
为什么你要知道：你的养护场景大概率是 Workflow（步骤固定、要可预测）。选 Workflow 不丢人，选对了才专业。

MCP Model Context Protocol · 模型上下文协议

一句话：一套统一的接口标准，让 AI 能插上各种系统和工具。
用人话说就是 Type-C 充电口。
没有它：每个品牌的充电线都不一样，你出门要带三根，还得配转接头。
有了它：一根线走天下，工具只要适配一次，所有支持 MCP 的 AI 都能直接用。
为什么你要知道：它是把 AI 接进那些老旧、不支持 AI 的系统的通用办法——而这正是 FDE 日常最头疼的活。Anthropic 的 FDE 岗位已经把"交付 MCP Server"写进职责了。

第 5 层怎么证明它真的有用

这一层是 FDE 和"会玩 AI 的人"的分水岭。别人做 Demo，你做验收。

Eval / 评估 Evaluation 分水岭

一句话：给 AI 出一套考试题，量化它到底做得好不好。
用人话说竣工验收。Demo 好看不算数，得按标准实测一遍才知道能不能交付。
为什么你要知道：没有 eval，你改了提示词之后根本不知道是变好了还是变坏了，只能靠感觉——这就是所谓的"盲飞"。课表 W10 是整个 90 天里最"FDE"的一周，做的就是这件事。

黄金数据集 Golden Dataset

一句话：找 20 条真实输入，你自己人工标注出"理想输出是什么"。这就是你的标准答案卷。
用人话说样板工程。先做出 20 个标准样本，以后所有 AI 的产出都跟它比。
为什么你要知道：这是你最值钱的资产，也是别人最懒得做、最抄不走的东西——因为它需要行业判断力，而这正是你的优势。课表 D10 就是专门做这个。

Grader / 评分器 Grader

一句话：阅卷方式，三种：代码判（快、客观、死板）、模型判（灵活、能判主观、需校准）、人判（最准、最贵、用来校准前两种）。
用人话说三种验收方式：仪器实测（客观但只能测硬指标）、技术员目测（灵活但要看人水平）、专家评审（最权威但请不起、且慢）。实际是三者组合用。

pass@k 和 pass^k

一句话：pass@k = 跑 k 次至少对一次的概率；pass^k = 跑 k 次全对的概率。
用人话说假设单次成功率 75%：
• 跑 3 次至少对 1 次 = 98%（pass@3）——给"辅助工具"用，错了人能改。
• 跑 3 次全对 = 42%（pass^3）——给"自动化系统"用，用户期望每次都对。
为什么你要知道：它逼你回答一个产品问题：这个系统是人看着用，还是自动跑？你现在的阶段显然只能是前者。

第 6 层工程名词（课表 W3 之后才需要）

这几个是"干活要用的工具"，不是 AI 概念。现在扫一眼有个印象就行。

名词一句话用人话说
Python干活用的主力工具一把多用工具箱。AI 圈的事实标准语言，你不需要精通，能看懂和改就行
pandasPython 里处理表格的库Excel 的超级版。几万行数据、批量清洗、自动统计，比手点 Excel 快得多
SQL查数据库的语言跟档案员问话的固定句式。"把 2026 年 K12 路段所有横向裂缝的记录按桩号排序给我"
ETL数据抽取、清洗、入库砂石料进场 → 筛分 → 入仓。AI 项目里这活儿通常占大头
Git版本管理工程日志 + 后悔药。每次改动都留档，随时能退回任意一天的状态
Docker把程序和环境一起打包集装箱。把你整个搅拌站打包运走，到哪个工地都能原样开工，不用重新配环境
FastAPI把程序变成一个能被访问的服务开一个服务窗口。别人来问，你的程序自动应答，不用你手动跑脚本
可观测性记录和监控系统运行状态拌合站的计量与台账。知道它跑了多少次、每次多慢、花了多少钱、哪次失败了
护栏 Guardrail防止 AI 越界的限制安全护栏和限速牌。比如"禁止输出养护等级判定""涉及金额必须转人工"

一句提醒，免得你走弯路：网上 90% 的"大模型教程"是教你怎么训练和微调模型的（Transformer、注意力机制、LoRA、RLHF……）。那些对你当 FDE 几乎没用——FDE 不训练模型，只是把别人训练好的模型用起来。

你要学的方向只有一个：怎么用好现成的模型。看到教程在讲"怎么造模型"，直接跳过。
给前两周的最低限度阅读安排：
D1 之前：读完 nowcoder 那篇名词详解（约 20 分钟）+ 本手册第 1、2 层。
D2 之前：读完本手册第 3、4 层，再看 2048ai 那 12 张图（约 20 分钟）。
第 5、6 层不用提前看——等课表走到 W2、W3 再回来查，提前看也记不住。
