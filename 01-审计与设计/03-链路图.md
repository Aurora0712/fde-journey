## 二、字段定义（步骤 N 的结构化输出）

| 字段名 | 类型 | 必填 | 取值约束 | 示例 |
|---|---|---|---|---|
| 桩号 | string | 是 | 匹配 `K\d+\+\d{3}` | K12+300 |
| 病害类型 | enum | 是 | 必须在标准类型表内 | 横向裂缝 |
| 严重等级 | enum | 否 | 轻度/中度/重度 | 中度 |
| 位置描述 | string | 是 | ≤ 50 字 | 距右侧路缘 1.2m |
| 发现时间 | datetime | 是 | ISO 8601 | 2026-09-30T09:20 |
